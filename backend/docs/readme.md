# 后端功能说明（实现对照）

本文件用于说明当前后端代码中已实现的功能与接口模块。

> 项目整体说明与完整功能清单请看仓库根目录：`README.md`。

## 模块与接口前缀

- 用户认证：`/auth/*`
- 商品：`/product/*`
- 分类：`/category/*`
- 收藏：`/favorite/*`
- 关注：`/follow/*`
- 求购：`/wanted/*`
- 聊天：`/chat/*`
- 评价：`/review/*`
- 举报：`/report/*`
- 管理员：`/admin/*`
- 通知：`/notification/*`

## 关键能力（已实现）

- JWT 登录态（普通用户与管理员区分：管理员 token 的 identity 形如 `admin_<id>`）
- 商品发布、列表、详情、我的商品、修改/状态修改、删除、图片上传、设置封面
- 求购发布、列表、详情、我的求购、状态更新、删除
- 收藏/取消收藏、收藏列表、是否收藏
- 关注/取消关注、关注/粉丝列表、是否关注、关注统计
- 会话/消息：会话列表、获取/创建会话、消息列表、发送消息、标记已读、未读数、图片上传、删除会话
- 评价：创建/详情/收到评价列表/发出评价列表/评分统计/删除
- 举报：创建/详情/我的举报列表；管理员（简化）举报列表/处理/删除
- 通知：管理员发送通知；用户通知列表/标记已读/全部已读/未读数
